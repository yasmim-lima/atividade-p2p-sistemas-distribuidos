# Atividade P2P - Sistemas Distribuídos

Projeto desenvolvido para a Atividade 01 da Unidade 2 da disciplina de Sistemas Distribuídos.

## Objetivo

Avaliar o desempenho da transferência de arquivos utilizando diferentes arquiteturas de comunicação distribuída.

## Arquiteturas

- Cliente-servidor sequencial
- Cliente-servidor concorrente
- Cliente-servidor com limite de clientes utilizando thread pool
- P2P

## Experimentos

Os experimentos serão realizados variando:

- Tamanho do arquivo;
- Quantidade de clientes.

Os tempos de transferência serão analisados considerando:

- Tempo mínimo;
- Tempo médio;
- Tempo máximo.

## Tecnologias

- Java 21
- Maven
- Git
- GitHub
